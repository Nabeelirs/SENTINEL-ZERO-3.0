# Verified scientific demonstration data

No satellite archive is committed here during release preparation.

After provider/contributor redistribution review and explicit publication
approval, the unchanged prepared archive may be provisioned as
`scientific_data.zip`. Alternatively the operator may set
`SENTINEL_ZERO_DEMO_ARCHIVE` to its existing local path. Visitors cannot select
that path. No automatic download, provider login or synthetic fallback is used.

Required size: **14,930,753 bytes**. SHA-256:
`6153417f06f71485a6cb85f5bc32defdc21e60495a47c2f66fdacda9f1e384cc`.
The independent embedded receipt is also pinned by the existing bootstrap.
This archive includes the six actual NISAR subsets and preserved preparation/
analysis products. Hash matching establishes recorded consistency, not NASA
authentication or independently validated science. See
[reproducibility](../docs/reproducibility.md) and
[data sources](../docs/nasa-data-sources.md).
